# 🍱 Surplus-to-Shelter PRO: Real-Time Urban Food Rescue OS
### *AmiHacks Hackathon — Problem Statement 1*

An enterprise-grade **Autonomous Food Rescue & Dynamic Logistics Platform** designed to solve perishable urban food waste by connecting hotels, banquet halls, restaurants, and supermarkets with verified shelters within the critical 2–4 hour consumption window.

---

## 🌟 Industry-Level Solution Highlights

1. **Enterprise Multi-Role Workspaces**:
   - **Mission Overview & Live GIS Map**: Interactive Jaipur urban corridor map tracking commercial donors, shelters, and cold-chain EV fleet.
   - **Commercial Donor Portal**: HACCP food safety holding temperature checks (>60°C hot, <5°C cold), Gemini AI vision scanner for automated calorie/weight estimation, and **Printable Section 80G CSR Tax Exemption Certificates** with digital verification seals.
   - **Shelter & NGO Operations Hub**: Live intake demand matrix, demographic breakdowns, allergen filters, and **Anti-Fraud 6-Digit Handover PIN Verification**.
   - **Fleet & VRP Logistics Center**: Vehicle Routing Problem with Time Windows (VRPTW) solver comparing unoptimized independent runs vs smart consolidated batching (**50.3% Fuel & Carbon Saved**).
   - **Municipal ESG & Regulatory Compliance Audit**: GHG Protocol Scope 3 abatement calculations ($2.5\text{ kg CO}_2\text{e}$ per kg food saved), landfill methane mitigation ($0.089\text{ kg CH}_4\text{/kg}$), and **One-Click CSV Audit Ledger Export**.
   - **AI Predictive Decay & Spoilage Forecaster**: Arrhenius microbial thermal acceleration model predicting safe consumption windows across ambient temperatures ($15^\circ\text{C}$ to $45^\circ\text{C}$) and banquet peak forecasts.

---

## 🛠️ Tech Stack

- **Frontend Framework**: React 19, Tailwind CSS, Lucide Icons, Canvas Confetti
- **Geospatial Engine**: Real-time SVG Vector GIS Map with Haversine distance heuristics
- **Build Tool**: Vite 8 (Ultra-fast HMR)
- **Audio Synthesizer**: Web Audio API Procedural Synthesizer (Zero asset bloat)
- **Standards Grounded**: US EPA WARM, GHG Protocol Scope 3, UN SDG 2 & SDG 12.3
